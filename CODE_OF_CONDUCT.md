# Code of conduct

This project follows the **[LGTM-HQ Code of Conduct](https://github.com/lgtm-hq/.github/blob/main/CODE_OF_CONDUCT.md)**.

By participating in **issues** and **pull requests** here, you agree to uphold that
policy. **Maintainers** may restrict or remove participation that violates it.

For questions about moderation, contact the maintainers via the channels described in
the org CoC document.
